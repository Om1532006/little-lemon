# Little Lemon DRF Capstone

Django REST Framework capstone with MySQL, Djoser registration/token authentication, menu and booking APIs, cart/orders, permissions and unit tests.

See `Readme.txt` for setup instructions and API paths for peer review.

## Quick start
1. Create MySQL database `littlelemon`.
2. Set `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT`.
3. Run `pipenv install`, `pipenv shell`.
4. Run `python manage.py makemigrations`, `python manage.py migrate`.
5. Run `python manage.py test` and `python manage.py runserver`.

Do not commit local credentials. This is an independently generated implementation based on the assignment brief, not the official course starter.
